# Datrix 本体图谱 UI 方案

## 首屏与布局

本体页面打开后，先看到业务对象的关系网。桌面端的图谱工作区采用三栏布局。顶部工具栏提供「图谱概览」「一跳邻域」和全图搜索。

| 区域 | 内容 |
| --- | --- |
| 左侧筛选 | 三层本体、节点类型、来源场景。默认显示全部层，保留跨层关系的端点，并显示筛选后的节点与关系数量。 |
| 中央画布 | 深蓝灰底配低对比点阵。实体、指标、规则和场景用不同颜色和形状区分。业务对象的名称贴近节点，线的箭头指向目标。 |
| 右侧检查器 | 选中节点时优先显示相邻关系，属性、来源和审核按对象的适用性展示。选中边时显示起点、终点、关系含义与证据。详情面板占独立空间，打开时保留画布焦点。 |

概览按连通分量分布。对较大的分量按实际连接关系做聚类，并用固定初始条件和节点 ID 保持自动布局可复现。较小分量和孤立节点也纳入浏览与搜索。首屏节点过多时，先显示代表节点及摘要，并在底栏注明实际展示数量和完整图的总量。三个本体层作为筛选条件，通过同一画布保留跨层连线。

节点大小按图中连接数分为少量档位，选中节点使用独立描边。实体为蓝色圆形，指标为青色菱形，分析规则为紫色六边形，场景为琥珀色圆角方形。业务关系采用实线，解释和映射关系采用虚线，具体含义以边名与详情为准。正常缩放下优先显示可辨认的节点名称，关系名在选中、悬停或进入邻域时出现，重叠的名称可在详情关系列表中读取。颜色之外同时使用形状、箭头和文字表达类型、方向和状态。

## 浏览与治理

1. 单击「科研论文」，高亮其直接连线。读图时可以按「教师 → 撰写 → 科研论文」顺着箭头读，也可以从右侧关系列表跳到相邻对象。
2. 双击节点或通过检查器的「查看一跳邻域」进入局部图。顶部标明当前中心，保留直接相连的入边和出边。选择其他节点仍可检查详情，通过「查看一跳邻域」把它设为新的中心。返回概览时恢复此前视口和筛选状态。
3. 搜索节点名称、别名或标识，结果来自当前修订的完整图。选中结果后将节点定位到画布，必要时提示并解除隐藏该节点的筛选。详情中的「来源」显示可用的场景、字段和证据，具体信息取决于对象类型。
4. 待审核对象在检查器显示状态和现有操作。审核队列的「在图谱中定位」复用同一套定位交互。较窄屏幕可收起筛选，详情移到画布下方。

## 与现有页面衔接

- 继续使用 React Flow，实现稳定的关系布局、缩放分级和选择高亮。已有的自动布局、保存布局、全屏操作可以收进画布工具区。保存位置按节点 ID 应用给当前修订中仍存在的节点。
- 从本体页面复用层级筛选、修订上下文和图谱定位逻辑。保存后的修订可使用已有的一跳邻域接口。草稿存在未保存改动时，从本地预览图计算邻域，确保画布反映当前草稿。
- 图谱是默认入口，Markdown 编辑及并排模式仍通过现有切换入口访问。窄列打开详情时优先保证可用画布宽度。

## 评审与验收

- 使用示例图验证读图路线。能从论文直接找到教师、刊物和论文数，也能从论文数继续追到去重口径及来源场景。
- 分别用图上节点、关系标签、右侧列表与搜索结果验证可达性。检查一跳邻域的入边与出边、跨层端点、清空筛选和无匹配状态。
- 用实际大图评估首屏可读性、缩放和选中响应，覆盖有保存布局的修订、未保存草稿、待审核跨场景关系和窄屏。原型用少量科研论文相关示例节点来评审布局和交互，真实数据密度由接入后的实图验证。
